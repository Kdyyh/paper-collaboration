## 成员空间

每位成员使用自己的 GitHub 用户名创建文件夹：

```text
members/
└── your-github-username/
    ├── README.md       # 个人介绍和资料索引
    ├── notes/          # 阅读笔记
    └── materials/      # 可分享的附件
```

## 网页使用方法

1. 接受仓库邀请并登录 GitHub。
2. 进入仓库，选择 **Add file → Create new file**，文件名填写 `members/你的GitHub用户名/README.md`，写入内容后点击 **Commit changes**，即可创建个人文件夹。
3. 进入个人文件夹，选择 **Add file → Upload files** 上传资料。
4. 编辑本页的“论文目录”，补充论文名称、论文链接和个人笔记路径。
5. 更新前先刷新页面；若遇到提交冲突，保留其他人的条目后再保存。

## 协作约定

- 所有受邀协作者具有相同的日常读写能力，可共同维护论文目录、创建文件夹和上传资料；仓库所有者额外负责成员和仓库设置。
- 个人文件夹表示资料归属，不提供独立的访问隔离；任何人都能查看公开内容，仓库协作者可以修改其中的内容。
- 默认各自维护自己的文件夹，修改或删除他人资料前先与本人沟通。
- 本仓库主要存放文献索引、阅读笔记及可分享资料；论文优先填写官方链接。
- 共享文件只上传有权分享的内容。
