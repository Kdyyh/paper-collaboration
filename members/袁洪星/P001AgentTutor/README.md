## 阅读笔记

### 研究问题
现有 LLM 智能教育系统（IES）基本是单轮静态问答，答完即止。局限包括：1.评估不出学习者的认知水平2.不能根据实时反馈调整教学策略
3.一次性给出答案。本文要解决的问题是：如何把教学变成一个有状态、多轮、可动态调整策略的闭环系统，让 LLM 不仅给答案，还能根据学生反应持续教

### 核心方法
**AgentTutor 五模块闭环**  
（1）**CDM（课程分解）**：按 Bloom 六层级（记忆→理解→应用→分析→评价→创造）把一门课拆成子目标树，作为教学骨架。  
（2）**LAM（学习者评估）**：逐轮出题打分，输出结构化状态（认知层级lj, 熟练度pj），供下游策略使用。  
（3）**DSM（动态策略）**：核心模块。借 LATS（语言智能体树搜索）+ 联网检索（Tavily）生成教案：每步撒 3 个候选、用 (U=λpφ+(1−λ)SC)打分、UCT 公式在利用已知好方案/探索冷门分支 间权衡、失败时写口头反思、奖励沿树回传。  
（4）**TRM（教学反思）**：按学生水平出练习、按 rubric 判分、生成下一轮问题。  
（5）**KEMM（记忆）**：Chroma 向量库存档学习档案与教学经验，跨轮检索。  
**外挂一个模拟学习者**：GPT-3.5，三种行为状态（困惑 / 学习 / 回答），带自己的知识库，且只能依据检索到的知识答题。

### 个人理解与疑问
**个人理解：**
   上述实验是不公平的，实验设置写明统一用 passive 模式 = 直接把教学文件展示给学生阅读。也就是说，学生根本没有跟老师对话，实际过程是老师联网搜资料 → 整理成一篇课文 → 学生阅读 → 把课文写进自己知识库 → 开卷答题。    
所以用Agent tutor和其他基线比较实际含义是："一个老师教过的开卷学生" vs "学生自己用各种刷题姿势闭卷做"。这就解释了为什么会出现 92.7 > GPT-4 闭卷 80.1这种反常数字。  
**疑问：文中未提过基线是否也联网，所以我默认没联**  
（1）若五个基线（CoT/ReAct/ToT/RAP/Reflexion）也拿到了同样的 10 轮和联网检索工具得分是否和AgentTutor接近？  
（2）我们由表一知有联网有教学的AgentTutor得分92.7，没有联网有教学的AgentTutor得分72.9，而没有教学没有联网的最强基线Reflexion得分68.1，却没有 "只给联网、不给教学" 的对照组？因此无法得知92.7里到底多少是检索、多少是教学？如果这组也能到 88、90—— 那教学组织没起什么作用，高分是因为学生开卷看到了答案。如果这组只能到 70 左右 —— 那说明学生自己读网资料读不懂、组织不成，教学组织确实在起作用    
（3）(pj)是 LLM 的主观打分，没有和真人教师评分对齐过，打分是否准确有依据？
