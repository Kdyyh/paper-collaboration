## 上传和整理资料

- 进入本文件夹，选择 **Add file → Upload files** 上传资料。
- 阅读笔记可以保存为 `notes/论文名称.md`。
- 可分享的附件可以放在 `materials/` 下。
- 创建子文件夹时，直接用“文件夹名/文件名”的形式新建文件即可。
- 如需加入公共论文目录，请同步更新仓库根目录的 README。

本文件夹属于公开仓库，任何人都可以查看；受邀协作者拥有编辑权限。
